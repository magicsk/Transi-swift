# Tech Stack

## Core Technologies
- **Language:** Swift
- **UI Framework:** SwiftUI
- **Platform:** iOS, WatchOS

## Supporting Libraries and Tools
- **Persistence:** SQLite
- **Networking:** Native URLSession (URLRequest)
- **Mapping:** MapKit
- **Live Activities:** ActivityKit
- **Intents:** AppIntents
- **Gzip:** Zlib / Gzip utility for compressed data handling

## Architecture
- **Pattern:** Provider-based/MVC with Controllers for specialized logic (Trip Planner, Virtual Table).
- **Design:** Modern SwiftUI lifecycle with @State, @Binding, and @EnvironmentObject for state management.
